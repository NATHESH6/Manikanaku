# Manikanaku
## Smart Time & Salary Calculator
Manikanaku is a Python-based time calculation web application built using Streamlit.
The application helps users calculate working hours, break time, and total salary accurately using ordinary time format (AM/PM).
## Project Overview

This project is designed for:

- Employees
- Freelancers
- Factory workers
- Office staff
- Shift workers
- Daily wage workers

## Users can enter:

- Starting time
- Ending time
- Break starting time
- Break ending time
- Price per hour

## The system automatically calculates:

Total working time
Break duration
Final work hours
Hours, minutes, seconds
Total salary amount
## Features
- Ordinary time input (AM/PM)
- Accurate hour/minute/second calculation
- Break time deduction
- Salary calculation per hour
- User-friendly interface
- Real-time calculation
- Streamlit web interface
- Night shift support
- Error handling for invalid time formats
